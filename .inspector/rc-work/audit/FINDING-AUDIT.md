# FINDING-AUDIT — RC1 Dogfood Campaign (Independent Audit)

Auditor: independent of the hunt subsystems. Date: 2026-08-22.
Scope: all candidate anomalies from six real-target hunts under `.inspector/rc-work/hunts/`.
Method: every classification below was re-derived from the cited artifacts
(`actions.jsonl`, `hunt.log`, run DBs) and from Inspector source — not accepted
from the hunt agents' self-classifications. Every "fix landed" claim was
spot-checked in the working tree (all fixes are currently **uncommitted**
working-tree changes on top of `b49eb5f`).

Severity policy: CRITICAL=security/destructive/secret/state-corruption/duplicate-visible-action; HIGH=false-positive factory/major finding loss/unrecoverable restart/broken clean install/real target unusable under supported config/stale worker applying work; MEDIUM=significant UX/degraded exploration/avoidable waste/incomplete diagnostics/nonfatal cleanup; LOW=minor ergonomics/docs.

## Hunt methodology audit

- **todomvc-react** — sound. The headline negative result (nav-only) was independently confirmed by querying the run DB; kind distribution matches exactly.
- **todomvc-backbone** — clean; correctly reported zero findings with no invented candidates.
- **vim-pty** — appropriately scoped bespoke harness; the one concession (VimBackend subclass for argv) is disclosed. Weakness: the original wedge evidence (exit 124 / AttachConsole text) is thin in retained artifacts — mitigated post-hoc by the committed-style repro script and N=5 regression test, which constitute better evidence than the original log.
- **calc-uia** — strong; evidence lines verified verbatim in `actions.jsonl`. Injection check (no SendInput/mouse/keybd) was performed and is good practice.
- **mspaint-uia** — solid, with self-identified harness noise (M-A3, coin-flip filter) that did not leak into conclusions. Its explicit reproduction-status table for calc gaps is exactly what cross-hunt auditing needs.
- **android-settings** — attempt-1 emulator was destroyed by the launch harness timeout (documented, retried cleanly); v1-explorer dead-end documented. Conclusions rest on v2, which is sound. Leaving the unrelated pre-existing `emulator-5554` zombie alone was correct.

No hunt's methodology undermines its final conclusions. One systematic caveat applies to four hunts: they ran on out-of-tree loops because ExploreController is web-only (W6), so "production bindings" were exercised but the production *explorer* was not, outside the web targets.

## Special notes requested

1. **React nav-only: is HIGH fair given the control app worked?** Yes. The control (backbone) app worked because its DOM happened to carry ids/labels; the React app is equally "supported configuration" (arbitrary localhost static target is the explicitly advertised RC1 capability), and class/placeholder-only DOM is the single most common real-world React shape. Under that config the explorer silently executed 250 actions with zero interactive coverage and zero findings — textbook "major finding loss," and worse, a *false clean bill of health* (`ok:true`, 0 findings) rather than an error. HIGH stands. It would not be CRITICAL because nothing crashed, no state was corrupted, and the failure mode is coverage loss, not wrongness.
2. **node-pty host-exit wedge:** classified honestly as TRUE_DEFECT with upstream origin in shipped dependency `@lydell/node-pty` 1.1.0. We own it because we ship and pin it; the mitigation (skip `kill()` for dead sessions, direct socket-worker disposal, armed force-exit guard) plus a real N=5 regression test are present in the working tree. Residual: the upstream defect itself remains; the guard trades a hang for a forced exit that could truncate late buffered output. Re-triage on dependency upgrade (noted in code).
3. **Claims lacking evidence:** none downgraded for total absence of evidence — all cited jsonl/log entries I checked existed and matched. One partial: vim V2's original crash text was not fully retained (see table); classification rests on the reproducible mechanism, now covered by the regression test.
